Development Resources

MDN Web Docs

Comprehensive HTML5, CSS3, and JavaScript documentation maintained by Mozilla. Used throughout development for syntax reference, accessibility attributes, and browser compatibility.

developer.mozilla.org

Quick reference for CSS selectors, Flexbox, Grid layout, and CSS custom properties. Particularly useful for cross-browser styling and responsive design techniques.

w3schools.com/css
JavaScript.info

Modern JavaScript tutorials used to implement DOM manipulation, event listeners, and dynamic content loading across the site's interactive sections.

javascript.info
PHP Manual — php.net

Official PHP documentation consulted for server-side scripting, form handling, and session management used in the site's back-end functionality.

php.net/manual
CSS-Tricks — Flexbox Guide

Detailed visual guide to CSS Flexbox and Grid layout, used to structure the responsive multi-column layouts throughout the website.

css-tricks.com
W3C Markup Validator

Used to validate all HTML and CSS against W3C standards, ensuring every page is well-formed and compliant with current web specifications.

validator.w3.org
WebAIM Contrast Checker

Colour contrast ratio tool used to verify all foreground/background combinations meet WCAG 2.1 AA accessibility guidelines across the site.

webaim.org

ign.com
