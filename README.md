    # NovaSpark Games

    A full-stack game store built for my MSc Computing (University of Sunderland).
    Customers can register, log in, browse, search, filter by genre and order;
    admins can add, edit and delete games and users.

    ## Tech stack
    PHP, MySQL, JavaScript, HTML/CSS

    ## Features
    - Password hashing, session-based login, role-based access (admin/customer)
    - Prepared statements and escaped output
    - Client-side and server-side form validation


    ## Setup
    1. Install XAMPP (or any PHP 8 + MySQL stack).
    2. Clone this repo into your web server folder (e.g. htdocs).
    3. Import `database/novaspark.sql` into MySQL (phpMyAdmin > Import).
    4. Copy `src/config.example.php` to `src/config.php` and enter your database details.
    5. Open http://localhost/novaspark-games/src/Entrance_Page.html
